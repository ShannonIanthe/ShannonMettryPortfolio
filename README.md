# 🚀 Developer Portfolio (One-Page Website)

A modern, high-end personal portfolio website built with **vanilla HTML, CSS, and JavaScript**. Designed with a premium UI aesthetic inspired by contemporary developer portfolios (glassmorphism, gradients, smooth animations).

## ✨ Features

- ⚡ Fully responsive one-page design
- 🎨 Modern UI with gradients and glassmorphism effects
- 🧭 Smooth scroll navigation
- 🪄 Scroll reveal animations
- 🧑‍💻 Clean experience timeline layout
- 📱 Mobile-friendly design
- 🚀 Ready to deploy on GitHub Pages or Vercel
